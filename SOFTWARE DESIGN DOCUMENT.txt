Kenduri Kahwin RSVP PWA Web App

 Prepared For: Family Wedding Organizing Committee
 Prepared By: Software Design Team

1. Executive Summary

KenduriAmpang RSVP is a Progressive Web Application (PWA) designed to simplify guest invitation management for a Malaysian wedding reception. The application enables invited guests to confirm attendance, indicate the number of attendees, select meal preferences, obtain location directions, and receive event updates.

The application will be mobile-first because most guests will access the invitation through WhatsApp. Guests can install the web app directly onto their Android or iPhone home screens without needing Google Play Store or Apple App Store publication.

2. Objectives
Business Objectives
Replace manual RSVP collection via WhatsApp.
Reduce uncertainty in catering headcount.
Track attendance by invitation group.
Simplify communication with guests.
Support event planning and reporting.
User Objectives

Guests should be able to:

View wedding invitation.
Confirm attendance in less than 1 minute.
Update RSVP before deadline.
View venue location via Google Maps/Waze.
Add event to personal calendar.

 ✅ RSVP Form
 ✅ Guest Count Tracking
 ✅ Google Maps/Waze
 ✅ WhatsApp Contact
 ✅ Admin Dashboard
 ✅ Excel Export

Skip QR check-in and e-Angpow initially. This MVP can be built in 1-2 weeks, hosted almost free on Vercel + Supabase, and is sufficient for managing 100-1000 wedding guests through WhatsApp invitation links.
